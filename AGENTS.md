## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Essay covers

Category visual systems for Writing essay covers: [docs/essay-cover-styles.md](docs/essay-cover-styles.md). Always use the category’s canonical reference when generating or regenerating covers.
